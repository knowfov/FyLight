# fyLight ⚡ — Ультимативный Оптимизатор для Вашего ПК

![fyLight Cover](https://raw.githubusercontent.com/knowfov/FyLight/main/assets/cover.jpg) <!-- Если есть обложка -->

**fyLight** — это мощное, современное и легкое приложение на базе Electron, созданное для тех, кто хочет выжать максимум из своей системы, сохраняя при этом эстетичный внешний вид. 

Забудьте о перегруженных интерфейсах прошлого. fyLight сочетает в себе стиль **Liquid Glass**, глубокую системную интеграцию и простоту использования.

---

## ✨ Основные возможности

### 📊 Мониторинг в реальном времени
Следите за состоянием вашего железа с точностью до процента.
- **CPU:** Точная нагрузка без лишних системных прерываний.
- **GPU:** Мониторинг дискретных и встроенных видеокарт.
- **RAM:** Тип памяти и её использование.
- **Storage:** Контроль свободного места на SSD/HDD.

![fyLight Cover](https://raw.githubusercontent.com/knowfov/FyLight/main/assets/2.jpg)
### 🛠 Ускорение и Твики
Десятки оптимизаций, разделенных по категориям, с мгновенным предпросмотром изменений:
- **Визуальные эффекты:** Отключение лишних анимаций для старых систем.
- **Сеть:** Оптимизация TCP и задержек (пинг) в играх.
- **Приватность:** Полное отключение телеметрии и слежки Windows.
- **Питание:** Управление схемами питания и парковкой ядер.



![fyLight Cover](https://raw.githubusercontent.com/knowfov/FyLight/main/assets/1.jpg)
### 📦 Сборки (Assemblies)
Новый подход к установке софта. Вместо ручного поиска — готовые карточки:
- **Готовые наборы:** Для геймеров, работы или минимализма.
- **Свои сборки:** Создавайте уникальные наборы приложений и твиков.
- **Установка в 1 клик:** Использует winget и прямые загрузки с GitHub.

### 🧹 Debloat (Очистка)
Удаление встроенного "мусора" Windows (Xbox, Погода, Cortana и др.), который обычно нельзя удалить стандартными средствами.

- **Liquid Glass:** Эффект матового стекла с глубоким размытием.
- **Темы:** Идеально проработанные Темная и Светлая темы.
