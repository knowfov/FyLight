    Отдельно от твиков выше: безопасная очистка временных файлов, кэша миниатюр, старого кэша обновлений Windows и корзины — сами игры, документы и настройки программ не трогает.

    Быстрые действия — разовые операции, не требуют применения через кнопку «Применить изменения» выше.

    Установка через winget (Steam, Chrome и другие) либо загрузка последнего релиза с GitHub (Zapret). Готовые сборки теперь во вкладке «Мониторинг».

    Загрузка списка приложений…

    Отметьте свои игры и нажмите «Оптимизировать выбранное». Применяется набор открытых, документированных приёмов Windows — те же самые, на которых работают платные бустеры вроде Razer Cortex или Wise Game Booster: отключение Xbox Game Bar/Game DVR и оптимизаций полноэкранного режима, аппаратное планирование GPU, максимальная схема электропитания, приоритет игрового процесса (если игра уже запущена), сетевые твики для снижения пинга (алгоритм Нейгла, снятие ограничения канала) и настройка системного профиля мультимедиа для игр. Никакой «секретной магии» или чудо-прироста FPS здесь нет — честно те же техники, что и у платных программ, но бесплатно и прозрачно.
